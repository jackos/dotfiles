# Zed Missing Features

This is a list of things I'd need to make Zed my daily driver:

- No persisted undo history.
- No local file history.
- No previous git file change diffing like gitlens in vscode.
- Can't set a default shell to open in new terminal, have to `chsh -s` which is not always desirable e.g. on remote machines.
- Remote connection can't open files outside of the project directory, zed command doesn't work on remote machine. Have to add a project to the workspace which is very annoying.
- Remote editing over ssh latency feels similar to neovim, vscode much faster when compared side-by-side.
